Leçon 5 : Types de données et structures en Python

1. Nombres

Entier = 10          # int
Flottant = 3.14      # float
Complexe = 2 + 3j    # complex

2. Chaînes de caractères

Texte = " Bonjour "
Print(texte[0])       # B
Print(len(texte))     # 7
Print(texte.upper())  # BONJOUR

3. Booléens

Vrai = True
Faux = False

Print(5 > 2)          # True
Print(" a " == " b ")     # False

4. Listes

Fruits = [" pomme ", " banane ", " orange "]
Print(fruits[1])         # banane
Fruits.append(" kiwi ")    # Ajoute à la fin
Fruits.remove("pomme ")   # Supprime un élément

5. Tuples (immuables)

Coordonnees = (10, 20)
Print(coordonnees[0])    # 10

6. Dictionnaires (clé-valeur)

Etudiant = {
    " nom " : " Alice ",
    " âge " : 22,
    "niveau " : " Licence "
}

Print(etudiant[" nom "])        # Alice
Etudiant[" niveau "] = " Master " # Modification

7. Ensembles (sets)

Nombres = {1, 2, 3, 3, 4}
Print(nombres)    # {1, 2, 3, 4}
Nombres.add(5)

8. Conversion de types

A = " 5 "
B = int(a) + 2
Print(b)  # 7
