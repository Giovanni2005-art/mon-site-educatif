Leçon 8 : Fonctions avancées et portée des variables

1. Paramètres par défaut

Def saluer(nom= "visiteur ") :
    Print(f "Bonjour {nom} ! ")

Saluer()
Saluer("Alice ")

2. Paramètres nommés

Def afficher_infos(nom, age, ville) :
    Print(f "{nom}, {age} ans, habite à {ville} ")

Afficher_infos(age=25, ville= "Lyon ", nom= "Maxime ")

3. Valeurs de retour multiples

Def calculs(x, y) :
    Return x + y, x * y, x – y

Somme, produit, difference = calculs(4, 2)
Print(somme, produit, difference)

4. Fonctions imbriquées

Def exterieur() :
    Def interieur() :
        Print(" Fonction intérieure appelée ")
    Interieur()

Exterieur()

5. Portée des variables

6. Utilisation de global et nonlocal

Def test_global() :
    Global x
    X = 100

Def test_nonlocal() :
    X = " externe "
    Def interne() :
        Nonlocal x
        X = " modifié "
    Interne()
    Print(" Valeur de x : ", x)

Test_nonlocal()
