Leçon 7 : Fichiers et gestion de fichiers en Python

1. Ouvrir un fichier (lecture seule)

Fichier = open(" donnees.txt ", " r ")
Contenu = fichier.read()
Print(contenu)
Fichier.close()

2. Lire ligne par ligne

Fichier = open(" donnees.txt ", " r ")
For ligne in fichier :
    Print(ligne.strip())
Fichier.close()

3. Écrire dans un fichier (remplace le contenu)

Fichier = open(" sortie.txt ", " w ")
Fichier.write(" Bonjour !\n ")
Fichier.write(" Ceci est un fichier texte. ")
Fichier.close()

4. Ajouter du contenu à un fichier

Fichier = open(" sortie.txt ", " a ")
Fichier.write(" \nNouvelle ligne ajoutée. ")
Fichier.close()

5. Utilisation du mot-clé with

La meilleure façon d’ouvrir un fichier : il se ferme automatiquement.

With open(" data.txt ", " r ") as f :
    For ligne in f :
        Print(ligne.strip())
