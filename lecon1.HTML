Leçon : Bases de Python

1. Introduction

Python est un langage de programmation interprété, simple et lisible. Il est largement utilisé dans les domaines de la data science, de l’IA, du développement web, etc.

2. Les variables

En Python, une variable est créée automatiquement lorsqu’on lui assigne une valeur :

A = 10
Nom = " Alice "
Pi = 3.14

3. Types de données

  • int : nombres entiers (ex : 10)
  • float : nombres décimaux (ex : 3.14)
  • str : chaînes de caractères (ex : " Bonjour ")
  • bool : booléens (True, False)

4. Affichage et types

Print(" Bonjour ")
Print(type(42))  # Affiche

5. Opérations de base

A = 5
B = 2

Print(a + b)  # Addition
Print(a * b)  # Multiplication
Print(a / b)  # Division
Print(a // b) # Division entière
Print(a % b)  # Modulo
Print(a ** b) # Puissance
