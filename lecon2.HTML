Leçon : Les conditions en Python

1. Utilisation des conditions

Les conditions permettent d’exécuter du code en fonction d’une situation donnée.

Age = 18

If age >= 18 :
    Print(" Vous êtes majeur. ")
Else :
    Print(" Vous êtes mineur. ")

2. `if`, `elif`, `else`

Note = 14

If note >= 16 :
    Print(" Très bien ")
Elif note >= 10 :
    Print(" Suffisant ")
Else :
    Print(" Insuffisant ")

3. Opérateurs de comparaison

  • `==` : égal à
  • ` !=` : différent de
  • `>` : strictement supérieur
  • `<` : strictement inférieur
  • `>=`, `<=` : supérieur ou égal, inférieur ou égal

4. Opérateurs logiques

  • `and` : et
  • `or` : ou
  • `not` : non

5. Exercice simple

Énoncé : Écris un programme qui demande l’âge de l’utilisateur (variable `age`) et affiche s’il peut voter (âge >= 18).
