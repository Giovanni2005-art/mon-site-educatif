Leçon 4 : Les fonctions en Python

1. Définir une fonction

Les fonctions permettent de réutiliser du code. On les définit avec le mot-clé def.

Def saluer() :
    Print("Bonjour ! ")

Saluer()

2. Paramètres et arguments

Def saluer(nom) :
    Print(" Bonjour ", nom)

Saluer(" Alice ")
Saluer(" Bob ")

3. Valeurs de retour

Une fonction peut retourner une valeur avec le mot-clé return.

Def carre(x) :
    Return x * x

Resultat = carre(5)
Print(resultat)

4. Arguments par défaut

Def bonjour(langage= "Python ") :
    Print(" Bonjour, programmeur en ", langage)

Bonjour()
Bonjour(" JavaScript ")
