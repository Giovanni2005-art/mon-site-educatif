Leçon : Les boucles en Python

1. La boucle `while`

Elle répète un bloc tant qu’une condition est vraie.

I = 0
While i < 5 :
    Print(i)
    I += 1

2. La boucle `for`

Parfaite pour parcourir une séquence (liste, chaîne, etc.).

For i in range(5) :
    Print("i = ", i)

3. Boucle sur une chaîne ou une liste

For lettre in " Python " :
    Print(lettre)

Fruits = [" pomme ", " banane ", " orange "]
For fruit in fruits :
    Print(fruit)

4. `break` et `continue`

# Interruption de la boucle
For i in range(10) :
    If i == 5 :
        Break
    Print(i)

# Saut d’une itération
For i in range(5) :
    If i == 2 :
        Continue
    Print(i)

5. Exercice

Énoncé : Affiche les nombres de 1 à 10 sauf le 5.
