Exercice final : Projet mini-gestionnaire de notes

Objectif : Crée un mini programme Python qui :

  • Demande à l’utilisateur son nom
  • Laisse entrer les notes d’élèves (nom + note)
  • Stocke ces données dans un dictionnaire
  • Affiche la moyenne générale
  • Affiche les élèves ayant une note ≥ 10 (admis)
  • Utilise au moins une fonction pour le calcul de moyenne
  • Utilise une boucle pour répéter la saisie jusqu’à ce que l’utilisateur dise " stop "
